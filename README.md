# Remix

Пример приложения [Remix](https://remix.run/), которое можно развернуть без настройки.

Remix v2 продолжает развиваться как [React Router](https://reactrouter.com/) в режиме фреймворка,
поэтому пример собран на React Router 8.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Статический сайт — сборка Railpack |
| Одностраничное приложение (SPA) | выключено |
| Путь до директории проекта | `/` |
| Директория сборки | `/build/client` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Путь проверки состояния | `/` |

Порт указывать не нужно: статический сайт отдаётся на порту 80. Railpack ставит зависимости и
запускает `npm run build` (`react-router build`). Серверный рендеринг выключен (`ssr: false` в
`react-router.config.ts`), страницы пререндерятся в HTML при сборке, готовые файлы — в
`build/client`. Страница в демо одна, поэтому SPA не нужен — несуществующий адрес отвечает 404.

В демо нет `package-lock.json`: версии пакетов выбираются при сборке по диапазонам из
`package.json`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
npm install

# запуск в дев режиме с отслеживанием изменений
npm run dev

# сборка для продакшн с минификацией
npm run build
```

Нужен Node.js 22.22 или новее.
